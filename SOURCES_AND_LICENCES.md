# Sources, licences and changes

The database `bible.sqlite` (published as a release file next to the apps) is built only from the sources below by `pipeline/build.py`. Each source keeps its own licence. The Swete Septuagint text from First1KGreek is CC BY SA 4.0, so the Swete tables as cleaned here are shared under CC BY SA 4.0 too, and this repository holds the code that produced them.

The app and pipeline code written for this project is licensed under the Apache License, Version 2.0 (see `LICENSE` and `NOTICE`; copyright 2026 Matthew Folson). That licence covers the code only. The Bible texts, lexicons, cross references and other data, and the fonts, are under the licences listed below, and the cleaned Swete text stays under CC BY SA 4.0.

## Changes made to the sources

* STEP Bible TAHOT: Hebrew words are stored byte for byte as published (`word.text_src`). A display form (`word.text`) removes only the morpheme dividers / and \. Verse text is built by joining the words; rows of type X (words supplied from the Septuagint) are left out of verse text. Hebrew is never Unicode normalised.
* STEP Bible TAGNT, TBESH, TBESG, TVTMS: imported as published, split into database columns. The app shows only TAGNT words marked as present in NA28 by default and hides the paragraph sign on screen.
* First1KGreek Swete: notes, headings and page furniture are removed, words split by line end hyphens are rejoined, and the corrected books from the sleeptillseven repository replace the matching First1KGreek books. Theodotion and Old Greek forms of Daniel, Susanna and Bel are kept as separate versions.
* eBible.org USFM texts: footnotes, cross reference notes, word attributes and headings are removed; Psalm titles are kept as verse 0.
* Nestle 1904 and Robinson Pierpont: verse text joined from the words; Strong's numbers cleaned of tense codes.
* OpenBible.info cross references and Strong's dictionaries: imported as published.

Full details: `pipeline/importers.py` and `pipeline/expected/reference_differences.md`.
