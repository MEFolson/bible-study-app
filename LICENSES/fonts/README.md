Ezra SIL's own notes say text converted to NFC or NFD order will not display correctly with it. The app shows TAHOT text in its published order and never normalises it.

Reserved Font Names: "SIL" and "Ezra" (Ezra SIL); "Gentium" and "SIL" (Gentium). The files are bundled unmodified, so the names may be kept.
