Made for offline study

Zagros Bible Study keeps the texts on your computer or phone. After you download it once, and after a phone finishes unpacking its database the first time, you do not need to be online. You can read Hebrew with vowel points, Aramaic, and Greek including the Septuagint, side by side with English, and use Strong's and cross references for detailed study anywhere.

Android

Open this page on your Android phone and tap the button.

Download for Android203.5 MB, works on any phone

Smaller file for most phones from recent years: 64 bit version, 166.6 MB. If it will not install, use the main button above.

How to install

  1. Make sure you have about 800 MB free: about 200 MB for the app and 445 MB for its Bible database. Android 7.0 or newer is needed.
  2. Tap the download button and wait for the download to finish.
  3. Open the downloaded file (from the notification, or from the Files or Downloads app).
  4. Android will ask whether to allow installs from this source. Tap Settings, switch on Allow from this source (on some phones it is called Install unknown apps), then go back and tap Install.
  5. If Play Protect says the app is unknown, choose to install anyway. This happens because the app does not come from the Play Store.
  6. Open Zagros Bible Study. The first time, it unpacks its database, which can take about a minute. A progress bar shows how far it is. After that it opens straight away and never needs the internet.
This is the first release. It has been tested on a computer but not yet on a phone, so please tell the person who sent you this link if anything goes wrong.

Windows

For Windows computers. Built on Windows 11 and checked there to make sure it opens.

Download for Windows164.3 MB

How to install

  1. Make sure you have about 650 MB of free space. The download is 164 MB and the unzipped folder is about 480 MB. You can delete the downloaded zip file afterwards.
  2. Click Download for Windows and wait for the download to finish. The file is called bible_study_windows.zip and is usually in your Downloads folder.
  3. Right click the zip file and choose Extract All, then click Extract.
  4. Open the BibleStudy folder that appears.
  5. Double click bible_study.exe.
  6. If Windows shows a blue box saying Windows protected your PC, click More info, then click Run anyway. This appears because the app is new and not signed by a publisher Windows knows.
  7. Keep the whole BibleStudy folder together. The program needs the other files and the data folder next to it, so move or copy the whole folder, not just the program. To make a shortcut, right click bible_study.exe and choose Show more options, then Send to, then Desktop (create shortcut).

The app works fully offline. A short READ ME FIRST.txt inside the folder repeats these steps.

For developers only: build it yourself

This zip has the app source and the database (download, 158.9 MB). It needs Flutter and Visual Studio 2022 with the Desktop development with C++ workload.

  1. Install Flutter for Windows by following the Flutter guide, then run flutter doctor.
  2. Extract the zip and open a terminal in the inner app folder, the one that holds pubspec.yaml.
  3. Run flutter pub get, then flutter build windows.
  4. The program is build\windows\x64\runner\Release\bible_study.exe. Keep the whole Release folder together.

Full notes are in the README inside the zip.
